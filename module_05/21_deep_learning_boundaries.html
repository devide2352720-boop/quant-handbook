第 21 讲：时序深度学习模型简析（LSTM / GRU / Transformer 适用边界） ​

本讲核心目标：
以极其冷静、客观、遵循买方工业现实的视角，审视时序深度学习（LSTM、GRU、Informer、Transformer）在 A 股多因子选股中的真实表现与适用边界；破除“样本行数很多就是大数据”的样本量幻觉；深入理解金融数据极低信噪比（SNR）与超参数量之间的“过拟合死结”；掌握 1D-CNN、GRU 与 Self-Attention 自注意力机制的归纳偏置；理清深度学习在 A 股真正能够发挥杀伤力的主战场（高频 Tick 与另类多模态数据）。

1. 深度学习在 A 股日频选股中的“骨感现实” ​

在学术界或自媒体文章中，深度学习往往被描绘为超越一切传统量化模型的“神级武器”。然而，在国内外顶尖对冲基金（如 Two Sigma、AQR、幻方、九坤）的真实投研中：在纯日频多因子选股任务上，深度学习模型的样本外超额往往并不显著优于精心调优的 LightGBM 或 CatBoost，甚至频繁因为过度拟合历史噪声而遭遇滑铁卢！

金融机器学习里程碑巨作 Empirical Asset Pricing via Machine Learning (Review of Financial Studies, 2020)（Gu, Kelly, & Xiu）对全美股历史进行了数十年的严密实证对比，得出了震撼业界的结论：浅层树模型与带正则化的浅层神经网络并驾齐驱，而过深、过复杂的深度模型在低信噪比环境下迅速退化！

2. 深度剖析：“数据量很大”的样本量幻觉 ​

很多量化工程师初看 A 股数据时会惊呼：“5,000 只股票 × 10 年 2,500 个交易日 = 1,250 万行面板数据！这难道不是标准的大数据吗？为什么不能上几千万参数的 Transformer？”

这是一个极其致命的“样本量幻觉（Degrees of Freedom Illusion）”：

  1. 截面强相关性：在任意一个交易日，这 5,000 只股票在很大程度上受到全市场宏观流动性、美元指数、地缘政治与产业板块 Beta 的共同驱动。当全市场大盘暴跌时，4,500 只股票同步下跌。这 5,000 行样本在统计学自由度上绝不等于 5,000 个独立样本，可能仅仅等价于 20~30 个独立的宏观因子驱动！
  2. 时序重叠性：若预测未来 5 日收益，相邻交易日的标签区间高度重叠，独立观测周期一年仅有 250/5=50 次！
  3. 参数量 vs 自由度倒挂：一个包含 4 层 Transformer、参数量达到 500 万的网络，面对实际独立信息自由度仅有数千次的金融截面历史，模型会瞬间凭借强大的容量将历史噪声一字不差地“死记硬背”下来！

3. 常见时序深度学习架构归纳偏置对比 ​

3.1 自注意力机制（Self-Attention）数学原理 ​

Attention(Q,K,V)=softmax(QKTdk)V

其中：

  • Q=XWQ,K=XWK,V=XWV 分别为输入特征矩阵在线性投影后的 Query、Key、Value；
  • 分母 dk 为缩放因子，防止内积过大导致 softmax 梯度饱和；
  • 金融因果掩码（Causal Masking）：在解码阶段必须严格施加下三角因果掩码，确保计算 t 时刻的注意力时，绝对无法看到 t+1 及以后的未来 Token！

4. 深度学习在 A 股真正能够发挥威力的“两大主战场” ​

既然深度学习在日频多因子上性价比不高，那么它在买方机构中的真正用武之地在哪里？

深度学习在 A 股量化的真正杀伤力阵地
├── 阵地 1: 高频微观盘口订单流 (Level-2 Tick Data / LOB):
│     ├── 数据特性: 单日全市场产生数千万条快照与逐笔流，信噪比显著提升，数据真正海量！
│     ├── 适用模型: DeepLOB (CNN + LSTM)、Temporal Convolutional Networks (TCN)
│     └── 业务目标: 预测未来 5 秒至 3 分钟的微观盘口买卖失衡，为算法执行交易 (VWAP) 节省冲击成本！
└── 阵地 2: 另类多模态非结构化数据 (Alternative Multi-modal Data):
      ├── 文本分析: FinBERT / 大语言模型处理上市公司业绩说明会音频文本、券商研报情绪提取
      ├── 图神经网络 (GNN): 构建全市场供应链、持股穿透与行业上下游拓扑图谱，捕捉风险传导！
      └── 卫星图像与货运数据: 卷积网络解析港口集装箱吞吐量、光伏电站红外热成像

5. 动手实操：CNN + GRU 轻量时序张量特征提取器实战 ​

下面的 Python 代码严格遵循工程规范，使用 PyTorch 构建一个轻量级的 AshareHybridSeqNet（1D-CNN + GRU 复合架构），接收滑动窗口张量输入并完成前向传播与梯度训练循环。

在项目根目录运行 PYTHONPATH=tutorial python3 -m examples.lecture_21_deep_learning_boundaries。依赖安装、共享模块和数据契约见项目说明。

py
"""
A 股日频时序深度学习模型简析 (1D-CNN + GRU 混合架构)
演示：合成三维张量上的 CNN/GRU 前向与训练循环；不是模型优劣实验
"""

from typing import Tuple
import numpy as np
import polars as pl
import torch
import torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader


class AshareTemporalCNNGRU(nn.Module):
    """
    轻量级时序卷积 + 门控循环单元混合网络
    输入形状: (Batch_size, Sequence_length, N_features)
    输出形状: (Batch_size, 1) 预测收益
    """

    def __init__(
        self,
        n_features: int,
        seq_len: int = 20,
        cnn_channels: int = 32,
        gru_hidden: int = 32,
        dropout: float = 0.30
    ):
        super().__init__()
        self.seq_len = seq_len

        # 1. 1D 卷积层：提取局部短周期量价微观形态 (如连续 3 天的 K 线组合)
        # Conv1d 期望输入形状: (Batch, Channels/Features, Seq_len)
        self.conv1 = nn.Conv1d(
            in_channels=n_features,
            out_channels=cnn_channels,
            kernel_size=3,
            padding=1
        )
        self.bn1 = nn.BatchNorm1d(cnn_channels)
        self.relu = nn.ReLU()

        # 2. 门控循环单元 (GRU)：捕获中周期跨期依赖与记忆遗忘
        self.gru = nn.GRU(
            input_size=cnn_channels,
            hidden_size=gru_hidden,
            num_layers=1,
            batch_first=True
        )

        # 3. 正则化与全连接预测头
        self.dropout = nn.Dropout(dropout)
        self.head = nn.Sequential(
            nn.Linear(gru_hidden, 16),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(16, 1)
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # x 形状: (B, T, F) -> 转置为 (B, F, T) 供 Conv1d 使用
        x_trans = x.transpose(1, 2)
        conv_out = self.relu(self.bn1(self.conv1(x_trans)))

        # 转回 (B, T, Channels) 供 GRU 处理
        gru_in = conv_out.transpose(1, 2)
        gru_out, _ = self.gru(gru_in)

        # 提取序列最后一个时间步的隐状态
        last_hidden = gru_out[:, -1, :]
        last_hidden = self.dropout(last_hidden)

        # 输出预测标量
        pred = self.head(last_hidden)
        return pred.squeeze(-1)


# ================= 合成张量训练演示 =================
if __name__ == "__main__":
    torch.set_num_threads(2)
    torch.manual_seed(42)
    np.random.seed(42)

    # 模拟输入参数
    batch_size = 64
    seq_len = 20     # 观察过去 20 个交易日的量价历史窗口
    n_features = 6   # 6 个基础量价指标 (开高低收量额)
    n_samples = 2000

    # 构造时序三维张量: (样本数, 20天窗口, 6特征)
    X_sim = np.random.normal(0, 1.0, (n_samples, seq_len, n_features)).astype(np.float32)
    
    # 模拟真实微弱信号 (最后 3 天的动量微弱主导)
    true_signal = (X_sim[:, -1, 0] - X_sim[:, -3, 0]) * 0.006
    y_sim = (true_signal + np.random.normal(0, 0.02, n_samples)).astype(np.float32)

    # 划分 80% 训练，20% 验证
    split_idx = int(n_samples * 0.8)
    train_ds = TensorDataset(torch.from_numpy(X_sim[:split_idx]), torch.from_numpy(y_sim[:split_idx]))
    val_ds = TensorDataset(torch.from_numpy(X_sim[split_idx:]), torch.from_numpy(y_sim[split_idx:]))

    train_loader = DataLoader(train_ds, batch_size=batch_size, shuffle=True)
    val_loader = DataLoader(val_ds, batch_size=batch_size, shuffle=False)

    model = AshareTemporalCNNGRU(n_features=n_features, seq_len=seq_len)
    criterion = nn.HuberLoss() # 使用鲁棒 Huber 损失防御异常跳动
    optimizer = torch.optim.AdamW(model.parameters(), lr=0.002, weight_decay=1e-3)

    print(">>> 开始训练 1D-CNN + GRU 神经网络 (观察训练集 vs 验证集误差演变)...")
    for epoch in range(1, 6):
        model.train()
        train_loss = 0.0
        for bx, by in train_loader:
            optimizer.zero_grad()
            preds = model(bx)
            loss = criterion(preds, by)
            loss.backward()
            optimizer.step()
            train_loss += loss.item() * len(by)
        train_loss /= len(train_ds)

        model.eval()
        val_loss = 0.0
        with torch.no_grad():
            for bx, by in val_loader:
                preds = model(bx)
                val_loss += criterion(preds, by).item() * len(by)
        val_loss /= len(val_ds)

        print(f"  Epoch {epoch:2d} | 训练集 Loss: {train_loss:.6f} | 验证集 Loss: {val_loss:.6f}")

    print("\n组件训练演示完成。本例没有真实股票滑窗、GBDT 对照或样本外收益验证，不能据此判断模型优劣。")

6. 本讲小结与课后动手作业 ​

核心知识图谱梳理： ​

  1. 破除样本量幻觉：截面强相关性与宏观 Beta 使得 1,200 万行日频数据的真实自由度大打折扣；
  2. 低信噪比与过拟合死结：超参数量过大的复杂深度网络极易在低信噪比金融数据中死记硬背噪声；
  3. 架构归纳偏置分工：CNN 抓局部形态、GRU 抓时序链条、Transformer 抓长程注意力；
  4. 找准真正主战场：高频 Level-2 微观订单流与另类文本图谱，才是深度学习最具不对称优势的核心阵地。
