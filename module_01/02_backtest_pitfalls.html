第 2 讲：量化回测的“四大死因”与防范心法 ​

本讲核心目标：
深入解剖导致量化策略在“实盘即爆雷”的四大微观机制：前瞻偏差（未来函数 / Look-ahead Bias）、幸存者偏差（Survivorship Bias）、不可成交撮合陷阱（Unexecutable Orders）与多重测试过拟合（P-Hacking & Overfitting）。通过数学形式化推导、A 股真实历史案例（退市股与封板机制）、Marcos López de Prado 的 Deflated Sharpe Ratio（DSR）与概率夏普比率（PSR）数学推导，构建坚不可摧的买方防御型回测系统。

1. 致命死因一：前瞻偏差（Look-ahead / Future Bias） ​

前瞻偏差指在计算历史某个时点 t 的因子特征、筛选标的或生成交易订单时，在信息论与因果时序上使用了在 t 时刻尚不可知的未来信息。

1.1 形式化数学定义与因果破缺 ​

设真实金融市场的信息生成过程为带过滤的概率空间 (Ω,F,{Ft}t≥0,P)，其中 Ft=σ(Xs:s≤t) 代表在时刻 t 之前全市场所有已经公开发生的信息代数流（包含成交快照、交易所公告、宏观数据等）。

  • 合规量化决策：在时刻 t 做出的目标持仓权重向量 wt 必须是 Ft-可测的（即 wt∈Ft）。
  • 前瞻偏差注入：只要存在任意微小的分量，使得决策函数 wt 依赖于未来的信息子集 Ft+Δt(Δt>0)，整个回测系统的鞅性质（Martingale Property）将瞬间破裂！所有基于该回测计算的超额收益、t 统计量、夏普比率全部蜕变为毫无统计学意义的虚假数字。

1.2 A 股中最隐蔽的四种未来函数形态 ​

形态 A：财报时间戳三元错位（Period Date vs Notice Date vs Revision Date） ​

上市公司财务报表包含三个完全不同的核心时间戳：

  1. 报告期截止日（Period End Date）：如一季报为 03-31，中报为 06-30，三季报为 09-30，年报为 12-31。
  2. 实际披露公告日（Notice Date）：上市公司将财报正式披露给公众的日期。A 股规定三季报必须在 10 月 31 日前披露，大量公司集中在 10 月 25 日至 10 月 30 日披露。
  3. 更正公告日（Revision Date）：财报发布后若被监管问询或审计发现错报，发布修正案的日期。
  • 业余代码：df.filter(pl.col("report_date") == "2023-09-30")，在 10 月初就根据“净利润同比暴增 200%”买入该股，这在现实中是超光速信息穿梭。
  • 买方解决方案：必须使用点时财务数据库（Point-in-Time, PIT），查询条件强制满足：Query Condition:report_period=’2023-09-30’ANDpublish_time<tdecision

2. 致命死因二：幸存者偏差（Survivorship Bias） ​

如果你的历史数据仓库中只包含当前仍在正常交易的股票，回测系统就默认赋予了策略“能够提前识别并自动避开所有未来会退市暴雷股票”的超自然能力。

2.1 ST 警示制度与流动性黑洞 ​

  • *ST / ST 风险警示：当上市公司连续亏损或存在重大财务造假违规时，交易所对其施加风险警示，日涨跌幅限制缩减为 ±5%。
  • 机构股票池底线：机构股票池有严格的“入库限制”，严禁买入风险警示股；若已有持仓遭遇 ST，必须在打开跌停板后第一时间平仓。
  • 如果回测不动态跟踪个股被 ST 的历史变迁，就会在个股断崖暴跌中误将其当成“严重超跌的便宜反转股”大举买入，实盘必死无疑。

3. 致命死因三：不可成交撮合陷阱（Unexecutable Orders） ​

任何量化回测的底层核心是撮合引擎（Matching Engine）。业余回测与买方回测的分水岭，就在于对极端行情下订单成交可能性的建模严谨度。

撮合陷阱类型业余回测中的幼稚假设A 股微观结构撮合现实实盘导致的灾难后果
一字涨停买入只要当天收盘涨幅 10%，模型在开盘以 Open 价格全额撮合成交集合竞价数十万手封单封死在买一，散户和中低频量化排单在队尾，实际成交概率严格为 0“涨停打板策略”回测年化收益 300%、夏普 5.0；实盘上线全部挂单失败，一笔都买不进去！
封死跌停卖出策略触发止损，在跌停板按 Close 价格瞬间平仓出场跌停板买盘全部撤单，买一为 0，卖一积压巨额抛单。全天几乎零成交，无法出场“严格止损策略”回测最大回撤仅 4%；实盘被迫连续锁仓硬抗 3~5 个一字跌停，单票亏损超 40%！
盘中临时停牌回测系统按停牌前最后价格每日计算持仓市值因重组、违规被交易所勒令停牌数月，账户流动性瞬间枯竭，资金无法调仓换股组合持仓发生被动剧烈漂移，复牌后通常连续无量跌停补跌。
大单市场冲击假设无论买卖 100 万还是 5000 万，均能以盘口同一价格成交平方根定律冲击模型：冲击成本与订单占日均成交量（ADV）比例的平方根成正比策略在小资金（50万）实测盈利，资金规模放大至 2000 万时，自己的买单推高了价格，Alpha 瞬间归零。

4. 致命死因四：过拟合与数据窥探（Overfitting & P-Hacking） ​

在金融量化领域，过拟合不是偶然现象，而是所有量化研究员必须每日对抗的默认状态。

4.1 Marcos López de Prado 的“量化七宗罪” ​

对冲基金研究先驱 Marcos López de Prado 在 2019 年发表的演讲与文献中，将量化金融研发中最常见的致命谬误归纳为“量化七宗罪（The 7 Sins of Quantitative Investing）”：

  1. 幸存者偏差（Survivorship Bias）：使用不包含退市标的的数据集。
  2. 前瞻偏差（Look-ahead Bias）：使用了事件发生时尚未公开发布的信息。
  3. 讲故事陷阱（Storytelling）：事后根据策略图表编造宏观或逻辑叙事来合理化噪声。
  4. 数据挖掘与数据窥探（Data Mining & Snooping）：通过遍历数万个特征，挑选恰好在历史样本上表现优异的特征。
  5. 低估交易与冲击成本（Cost Underestimation）：忽视滑点、印花税与市场冲击的非线性增长。
  6. 离群值与非平稳性忽视（Outliers & Non-stationarity）：未对厚尾极端分布进行鲁棒处理。
  7. 隐蔽做空波动率（Short Volatility Trap）：策略通过隐蔽承担巨大尾部风险来获取平时平稳的微小收益（如雪球期权结构）。

4.2 概率夏普比率（PSR）与压缩夏普比率（DSR）数学推导 ​

设策略在 T 个观测周期内的样本平均收益率为 μ^，样本标准差为 σ^，样本夏普比率为 SR^=μ^σ^。若收益率序列存在偏度 γ^3（Skewness）与峰度 γ^4（Kurtosis），根据 Mertens (2002) 与 Bailey & López de Prado (2012) 的渐近正态展开，样本夏普比率的渐近方差为：

σ^SR^2=1T−1(1−γ^3SR^+γ^4−14SR^2)

概率夏普比率（Probabilistic Sharpe Ratio, PSR）： ​

衡量策略真实夏普比率大于基准阈值 SR∗ 的概率：

PSR(SR∗)=Φ((SR^−SR∗)T−11−γ^3SR^+γ^4−14SR^2)

其中 Φ(⋅) 为标准正态累积分布函数（CDF）。

压缩夏普比率（Deflated Sharpe Ratio, DSR）： ​

当一个研究员独立测试了 K 个不同的策略或参数组合，并挑选出其中的最大夏普比率 SR^max 时，K 次测试中最大值的期望并非为 0。根据极值理论（Extreme Value Theory），在零假设下 K 个相互独立（或弱相关）的试验中所能取得的最大夏普基准期望值 SR0 为：

SR0=V({SRk})[(1−γ)Φ−1(1−1K)+γΦ−1(1−1K⋅e)]

其中：

  • γ≈0.5772156649（Euler-Mascheroni 常数）；
  • V({SRk}) 为所有 K 次试验中夏普比率的横截面方差；
  • K 为研发过程中尝试过的试验总次数（Number of Trials）。

DSR 的最终定义为将最大夏普代入以极值期望 SR0 为基准的概率夏普公式：

DSR≡PSR(SR0)=Φ((SR^max−SR0)T−11−γ^3SR^max+γ^4−14SR^max2)

核心启示：当你在策略研发中尝试了 500 次参数（K=500），原本看似亮眼的夏普比率在 DSR 检验下会发生断崖式暴跌。如果 DSR 低于 0.95，说明该策略极大概率只是多重测试撞大运的过拟合产物！

"""
lecture_02_backtest_sanitizer.py
合成日频案例：比较信号时点与撮合约束，演示现金持仓核算和 DSR
"""
import numpy as np
import pandas as pd
from scipy.stats import norm, skew, kurtosis
from dataclasses import dataclass
from typing import Tuple, Dict

@dataclass(frozen=True)
class TradeExecutionRules:
    can_buy_on_limit_up: bool = False   # 严格禁止涨停买入
    can_sell_on_limit_down: bool = False # 严格禁止跌停卖出
    one_way_commission: float = 0.00015  # 单边万1.5
    stamp_duty: float = 0.0005           # 卖方印花税 0.05%
    slippage_bps: float = 0.0005         # 基础滑点万分之5

class AshareBacktestSanitizer:
    def __init__(self, rules: TradeExecutionRules | None = None):
        self.rules = rules or TradeExecutionRules()

    def simulate_mock_ashare_universe(self, n_days: int = 500, n_stocks: int = 5) -> pd.DataFrame:
        """
        生成教学合成行情；不代表交易所真实日历、限价规则或退市过程。
        """
        np.random.seed(42)
        dates = pd.date_range("2023-01-01", periods=n_days, freq="B")
        all_dfs = []

        for stock_id in [f"{i:06d}.SZ" for i in range(1, n_stocks + 1)]:
            # 基础随机游走收益率
            base_ret = np.random.normal(0.0003, 0.022, size=n_days)
            
            # 人工注入 3% 概率的一字涨停与 2% 概率的封死跌停
            limit_up_mask = np.random.binomial(1, 0.03, size=n_days).astype(bool)
            limit_down_mask = np.random.binomial(1, 0.02, size=n_days).astype(bool) & ~limit_up_mask
            
            base_ret[limit_up_mask] = 0.0998  # 封死涨停
            base_ret[limit_down_mask] = -0.0998 # 封死跌停

            close = 10.0 * np.cumprod(1 + base_ret)
            open_p = close * (1 + np.random.normal(0, 0.003, size=n_days))
            # 保证价格物理合理性
            high_p = np.maximum(open_p, close) * (1 + np.abs(np.random.normal(0, 0.005, size=n_days)))
            low_p = np.minimum(open_p, close) * (1 - np.abs(np.random.normal(0, 0.005, size=n_days)))

            locked = limit_up_mask | limit_down_mask
            open_p[locked] = high_p[locked] = low_p[locked] = close[locked]

            df = pd.DataFrame({
                "trade_date": dates,
                "symbol": stock_id,
                "open": open_p,
                "high": high_p,
                "low": low_p,
                "close": close,
                "returns": base_ret,
                "is_limit_up": limit_up_mask,
                "is_limit_down": limit_down_mask
            })
            all_dfs.append(df)

        return pd.concat(all_dfs, ignore_index=True)

    def run_backtest_engine(
        self,
        df: pd.DataFrame,
        use_future_leakage: bool = False,
        enforce_liquidity_constraints: bool = True
    ) -> Dict:
        """
        回测主推进引擎：支持在合规模式与漏洞模式之间切换对比
        """
        if df.duplicated(["symbol", "trade_date"]).any():
            raise ValueError("股票日期主键重复")
        df = df.sort_values(["trade_date", "symbol"]).reset_index(drop=True)
        symbols = df["symbol"].unique()
        dates = df["trade_date"].unique()
        if len(dates) < 2 or len(df) != len(dates) * len(symbols):
            raise ValueError("示例要求至少两天且每个交易日覆盖相同股票全集")
        if not np.isfinite(df[["open", "close", "returns"]].to_numpy()).all() or (df[["open", "close"]] <= 0).any().any():
            raise ValueError("行情需为有效有限数值")
        df["signal"] = (df["returns"] > 0).astype(int)
        if not use_future_leakage:
            df["signal"] = df.groupby("symbol")["signal"].shift(1).fillna(0).astype(int)
        # 固定初始资金分仓，仓间不再平衡；未投资部分保留现金。
        # 每只股票每天只在开盘做一次交易，新买入持仓不会同日卖出。
        cash = {symbol: 1.0 / len(symbols) for symbol in symbols}
        shares = {symbol: 0.0 for symbol in symbols}
        previous_nav = 1.0
        portfolio_daily_returns = []
        buy_cost = self.rules.one_way_commission + self.rules.slippage_bps
        sell_cost = buy_cost + self.rules.stamp_duty
        if min(buy_cost, sell_cost) < 0 or sell_cost >= 1:
            raise ValueError("交易成本率不合法")
        for day in dates[1:]:
            nav = 0.0
            for _, row in df[df["trade_date"] == day].iterrows():
                symbol = row["symbol"]
                buy = row["signal"] == 1 and shares[symbol] == 0
                sell = row["signal"] == 0 and shares[symbol] > 0
                suspended = ("volume" in row and (pd.isna(row["volume"]) or row["volume"] <= 0))
                if enforce_liquidity_constraints:
                    buy = buy and not suspended and (not row["is_limit_up"] or self.rules.can_buy_on_limit_up)
                    sell = sell and not suspended and (not row["is_limit_down"] or self.rules.can_sell_on_limit_down)
                if buy:
                    shares[symbol] = cash[symbol] / (row["open"] * (1 + buy_cost))
                    cash[symbol] = 0.0
                elif sell:
                    cash[symbol] = shares[symbol] * row["open"] * (1 - sell_cost)
                    shares[symbol] = 0.0
                nav += cash[symbol] + shares[symbol] * row["close"]
            portfolio_daily_returns.append(nav / previous_nav - 1)
            previous_nav = nav
        returns_arr = np.asarray(portfolio_daily_returns)
        std_ret = np.std(returns_arr, ddof=1) if len(returns_arr) > 1 else 0.0
        annual_sharpe = np.sqrt(252) * np.mean(returns_arr) / std_ret if std_ret > 0 else 0.0
        return dict(sharpe_ratio=annual_sharpe, cumulative_return=previous_nav - 1,
                    mean_daily_return=np.mean(returns_arr), returns_series=returns_arr)

    @staticmethod
    def calculate_deflated_sharpe_ratio(
        returns: np.ndarray, num_trials: int = 1, benchmark_sharpe: float = 0.0,
        trial_sharpe_std: float | None = None,
    ) -> float:
        """DSR 参考公式。夏普、基准与试验间标准差均为单期口径。

        num_trials 为独立试验次数假设；多次试验必须提供完整搜索的夏普离散程度。
        结果不是“策略真实”的贝叶斯后验概率，不单独处理收益自相关。
        来源：https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf
        """
        returns = np.asarray(returns, dtype=float)
        if returns.ndim != 1 or len(returns) < 3 or not np.isfinite(returns).all():
            raise ValueError("至少需要三个有限的单期收益观测")
        if not isinstance(num_trials, int) or num_trials < 1 or not np.isfinite(benchmark_sharpe):
            raise ValueError("试验次数和基准不合法")
        standard_deviation = np.std(returns, ddof=1)
        if standard_deviation <= 0:
            raise ValueError("常量收益没有可估计的夏普标准误")
        sr = np.mean(returns) / standard_deviation
        threshold = benchmark_sharpe
        if num_trials > 1:
            if trial_sharpe_std is None or not np.isfinite(trial_sharpe_std) or trial_sharpe_std < 0:
                raise ValueError("多次试验需要提供单期夏普的试验间标准差")
            gamma = 0.5772156649
            max_z = ((1 - gamma) * norm.ppf(1 - 1 / num_trials) +
                     gamma * norm.ppf(1 - 1 / (num_trials * np.e)))
            threshold += trial_sharpe_std * max_z
        variance_term = 1 - skew(returns, bias=False) * sr + (kurtosis(returns, fisher=False, bias=False) - 1) * sr**2 / 4
        if not np.isfinite(variance_term) or variance_term <= 0:
            raise ValueError("无法估计有效夏普标准误")
        return float(norm.cdf((sr - threshold) * np.sqrt(len(returns) - 1) / np.sqrt(variance_term)))

7. 买方机构级回测必备自检清单（Pre-Flight Checklist） ​

在将任何量化模型提交投委会或上线实盘前，必须逐条对照以下 8 项黄金核对清单：

text
[ ] 1. 严格时序分离：特征时间戳严格早于决策时间戳，信号在 t 日收盘后生成，执行在 t+1 日开盘或盘中。
[ ] 2. 点时财务查询 (PIT)：财报使用实际公告披露日 (Notice Date)，严禁使用报告期截止日 (Period Date)。
[ ] 3. 历史全集与退市股票：历史标的池必须包含当时存在、后续退市的全部股票，杜绝幸存者偏差。
[ ] 4. 真实撮合限价：封死涨停板严禁撮合买单，封死跌停板严禁撮合卖单，未成交委托保留在待成交队列。
[ ] 5. 停牌与流动性处理：因重组、核查停牌的标的严禁假设可按最新价清仓，持仓保持锁死状态。
[ ] 6. 严密账本对账：卖方印花税 (0.05%)、券商佣金、过户费与市场冲击滑点买卖双边精细计提，现金流完全自洽。
[ ] 7. 样本外盲测隔离：回测区间确定前严格封存最近 12 个月的数据作为真盲测（Out-of-Sample），严禁反复偷看。
[ ] 8. 多重测试校正：记录调参总次数，计算 Deflated Sharpe Ratio (DSR)，确认统计显著性。

8. 本讲小结与课后实战作业 ​

核心记忆点： ​

  • 未来函数是量化死罪：财报披露日混淆、日内价量颠倒、全局特征标准化，是最常见的隐形刺客。
  • 幸存者偏差抹杀风险：不把已退市股票算进历史回测，就等于假设自己拥有未卜先知的超自然能力。
  • 没有滑点与撮合限制的回测一文不值：涨停板买不到、跌停板卖不掉，是 A 股最重要的现实物理法则。
  • 多重测试需以 DSR 严谨验真：不要把在样本内尝试了上千次碰巧撞出的虚高夏普当成真实的 Alpha。
