第 24 讲：凸优化求解器（cvxpy）实战 ​

本讲核心目标

在现代买方量化机构中，“机器学习打分（Alpha）”只是前置原料，**投资组合凸优化（Portfolio Convex Optimization）**才是将预测转化为稳健资管产品的“总装反应炉”。

初级量化研究员往往按预测分数挑选前 50 或 100 只股票等权买入，结果组合无意识暴露了数十个百分点的行业偏斜和小市值下沉风险，一旦市场风格突变便遭毁灭性回撤。本讲融合 MSCI Barra 组合构建规范 与 华泰证券多因子体系优化模型：系统推导指数增强（Index Enhancement）二次规划（QP）与二阶锥规划（SOCP）数学模型；详解利用 Barra 结构化特性在 cvxpy 中降维提速至毫秒级的核心算法；严格构建行业硬中性、市值偏离容差、个股超配上限与预测跟踪误差（TE）硬上限；并推导**因子边际风险贡献（FMCAR）**对主动风险来源的穿透解析！

1. 经典文献与工业界理论基石 ​

构建严谨的组合优化系统，离不开数学规划与现代金融工程的经典文献支持：

  1. Markowitz, Harry (1952). "Portfolio Selection", The Journal of Finance, 7(1): 77-91.

    现代投资组合理论（MPT）奠基之作，首次将投资决策转化为均值-方差二次规划极值问题。

  2. Boyd, Stephen, & Vandenberghe, Lieven (2004). Convex Optimization. Cambridge University Press.

    全球运筹学与凸优化圣经，系统阐释了凸集、凸函数、对偶理论（KKT 条件）、二次规划（QP）与二阶锥规划（SOCP）的标准范式。

  3. 华泰证券研究所 (林晓明、陈烨, 2016). 《华泰多因子模型体系初探——华泰多因子系列之一》, 第四部分：优化模型.

    系统推导了国内 A 股指数增强下的二次规划目标函数、哑变量行业中性约束矩阵、个股非负下界约束及因子边际风险贡献（FMCAR）解析体系。

  4. Boyd, S., Busseti, E., He, S., & Kang, J. (2017). "Multi-Period Trading via Convex Optimization", Foundations and Trends in Optimization, 3(1): 1-76.

    斯坦福大学 Boyd 团队关于凸优化在买方多期量化交易中的前沿综述，详述了交易成本、冲击与跟踪误差的多目标求解。

  5. Lobo, M. S., Vandenberghe, L., Boyd, S., & Lebret, H. (1998). "Applications of second-order cone programming", Linear Algebra and its Applications, 284(1-3): 193-228.

    证明了二次风险约束可通过 Cholesky 分解严格转化为二阶锥约束（Second-Order Cone, SOC），为内点法高效求解奠定基础。

2. 为什么“等权选股”在指数增强实盘中是死路一条？ ​

许多量化团队训练出了 Rank IC 高达 8% 的 LightGBM 预测模型，但当他们按预测得分挑选前 50 只股票直接等权买入时，回测净值往往被基准指数（如中证 500、中证 1000）严重抛离。

根本原因在于：未加风险控制的主动投资组合，本质上是在用全部净值豪赌行业和风格！

3. 指数增强组合优化的严谨数学建模 ​

设全市场可交易股票池（或基准成分股扩展池）共有 N 只股票。

3.1 决策变量与主动偏离权重 ​

  • w∈RN：待求解的投资组合持仓权重向量（决策变量）；
  • wb∈RN：基准指数成分权重向量（如中证 500 成分股权重，满足 1Twb=1,wb,i≥0）；
  • h=w−wb∈RN：主动偏离权重向量（Active Weights）。

3.2 组合优化的三大经典形式（华泰多因子框架） ​

在买方实际运作中，二次规划通常有以下三种等价变换形式：

  1. 形式一（给定风险预算，最大化收益）：maxhhTαs.t.hTΣh≤σmax2
  2. 形式二（给定预期收益目标，最小化风险）：minhhTΣhs.t.hTα≥αtarget
  3. 形式三（风险惩罚均值-方差效用最大化，工业界最常用）：maxwU(w)=hTαH⏟持有期主动预期超额收益−λ2hTΣHh⏟持有期跟踪误差方差惩罚

其中：

  • αH∈RN：经第 22 讲样本外校准的持有期 H 日预期主动超额收益率向量；
  • ΣH=HAΣann∈RN×N：将年化 Barra 协方差折算为持有期协方差；
  • λ>0：风险厌恶系数（Risk Aversion Parameter）。

4. Barra 结构化低维加速（cvxpy 算力优化秘籍） ​

若在 cvxpy 中直接书写 cp.quad_form(h, Sigma)，当 N=5,000 时，生成一个 5,000×5,000 的稠密二次型需要处理 2,500 万项乘加，导致求解器内存耗尽或耗时数分钟。

利用上一讲推导的 Barra 结构化分解 Σ=XFXT+Δ，主动风险方差可以化简为：

hTΣh=hT(XFXT+Δ)h=(XTh)TF(XTh)+hTΔh

定义主动因子暴露向量为 y=XTh∈RK（维度仅为 K≈40∼60！），目标函数中的风险项转化为：

hTΣh=yTFy+∑i=1Nδihi2

在 cvxpy 中，这一变换不仅将内存消耗降低 99%，而且严格符合 DCP（Disciplined Convex Programming）规范：

python
# cvxpy 结构化低维算力优化实现
active_factor_exp = cp.matmul(X.T, h)          # (K,) 维线性变换
factor_risk = cp.quad_form(active_factor_exp, F) # 仅 (K, K) 维小矩阵二次型！
specific_risk = cp.sum(cp.multiply(delta, cp.square(h))) # (N,) 向量逐元素相乘！
total_variance = factor_risk + specific_risk

5. A 股实盘约束系统全解 ​

实盘指数增强模型必须施加多维硬性与弹性约束，以满足基金合同与中国证监会监管法规：

5.1 资金预算与单边多头约束（Budget & Long-Only） ​

∑i=1Nwi=1,wi≥0,∀i∈{1,2,…,N}

在主动权重形式下：

∑i=1Nhi=0,hi≥−wb,i,∀i

因为无法裸卖空股票（wi≥0），个股主动权重的物理下限自然就是其在基准中的权重的负值 −wb,i！

5.2 行业硬中性约束（Industry Neutrality） ​

设 S=Xind∈RN×31 为申万 31 个一级的 One-Hot 行业哑变量矩阵：

∑j=1Nhjsji=0,∀i∈{1,…,31}⟺XindT(w−wb)=0

此约束强制组合在每一个一级行业上的配置比例与基准指数严丝合缝，彻底剔除行业轮动 Beta 波动。

5.3 风格因子偏离容忍约束（Style Tolerance） ​

防止模型为博取收益而隐性向微盘股、高波动股票下沉：

|XstyleT(w−wb)|≤δstyle

例如设定对数市值风格主动暴露 |ΔSize|≤0.05σ，确保组合在市值维度与基准紧密贴合。

5.4 个股权重主动偏离上下限（Active Stock Bounds）与“双十原则” ​

  1. 相对基准超配上限：−wb,i≤hi≤dmax实盘中中证 500 指增通常设定 dmax=1.0%∼1.5%，中证 1000 指增设定 dmax=0.5%∼0.8%；
  2. 绝对持仓上限（公募“双十原则”）：单只股票持仓市值不得超过基金资产净值的 10%（实盘指增通常单股上限设为 2%∼3% 以极致分散特异风险）。

5.5 预测跟踪误差硬上限（Tracking Error Hard Bound） ​

目标函数中的风险厌恶系数 λ 仅提供惩罚权重，无法直接保证跟踪误差低于合同上限。因此必须显式施加二次锥约束：

hTΣannh≤TEmax2

6. 因子边际风险贡献（FMCAR）与主动风险穿透解析 ​

华泰证券多因子报告系统推导了组合优化完成后，如何通过解析求导反向穿透追踪风险来源：

6.1 因子对主动风险的边际贡献（FMCAR）公式 ​

组合的总主动方差为：

σP2=xPATFxPA+hPATΔhPA

其中 xPA=XThPA∈RK 为组合的主动因子暴露。

对主动因子暴露求偏导数，定义因子对主动风险的边际贡献（Factor Marginal Contribution to Active Risk, FMCAR）：

FMCAR=∂σP∂xPAT=FxPAσP

6.2 主动风险精准加总分解 ​

由矩阵乘法展开，得到因子风险对主动波动率的贡献：

xPAT⋅FMCAR=xPATFxPAσP

总主动跟踪误差 σP 严格分解为系统因子贡献与个股特异贡献两部分：

σP=∑k=1KxPA(k)⋅FMCAR(k)+hPATΔhPAσP
  • 实战意义：在完成组合优化后，投资经理可直接打印每个因子的边际贡献 xPA(k)⋅FMCAR(k)。若发现 Size 因子的风险贡献占比达到 40%，即可迅速警觉市值暴露过载，并在优化器中调紧市值容差参数。

7. 现代凸优化求解器选型：Clarabel vs OSQP vs MOSEK ​

求解器 (Solver)算法架构是否支持 SOCP 跟踪误差硬约束开源/商业许可求解速度与数值精度工业界应用场景
Clarabel原生内点法（Interior Point Method）✅ 原生支持开源（Apache 2.0，Rust 内核）极高精度，对病态矩阵极稳健，毫秒级收敛cvxpy 官方推荐首选现代化开源锥求解器
OSQP交替方向乘子法（ADMM）❌ 仅支持标准线性约束 QP开源（Apache 2.0）极快（早期迭代），但达到极高精度收敛较慢适用于无二次风险硬约束的大规模高频 QP 优化
MOSEK工业级对偶原点内点法✅ 原生支持商业闭源（学术免费）工业界全球金标准，极速稳定，鲁棒性登峰造极头部百亿量化私募与主权基金生产标配
SCS分裂圆锥求解器（ADMM）✅ 支持开源（MIT）适合超大规模问题，但数值精度较低适用于快速原型验证

在 tutorial/examples/lecture_24_cvxpy_portfolio_optimization.py 中，我们实现了生产级 AshareIndexEnhancementOptimizer：

  2. 完整构建行业硬中性、市值容差、个股主动超配与年化跟踪误差硬上限约束；
  3. 输出最优配置权重 w∗，并严格校核每一项 KKT 约束残差。

py
"""
教学用 A 股指数增强凸优化器 (AshareIndexEnhancementOptimizer)
基于 cvxpy 与 Barra 结构化风险模型构建
实现：行业硬中性、市值约束、个股上下界限制与二次跟踪误差惩罚
"""

from dataclasses import dataclass
from typing import Dict, List, Optional, Tuple
import cvxpy as cp
import numpy as np
from examples.portfolio_utils import validate_risk_inputs, solve_checked


@dataclass
class OptimizationResult:
    """优化结果与组合全景体检报告"""
    horizon_days: int
    optimal_weights: np.ndarray
    expected_active_return: float
    annualized_tracking_error: float
    active_share: float
    effective_stocks_count: int
    industry_max_deviation: float
    size_style_deviation: float
    status: str

    def print_dossier(self):
        """格式化打印优化报告"""
        print("=" * 70)
        print(f"🎯 指数增强凸优化求解报告 [求解状态: {self.status}]")
        print("=" * 70)
        print("【核心收益与主动风险】")
        print(f"  • 预期持有期主动超额 (Alpha)  : {self.expected_active_return * 100:8.2f}%")
        print(f"  • 预期年化跟踪误差 (TE)     : {self.annualized_tracking_error * 100:8.2f}%")
        print(f"  • 收益预测持有期             : {self.horizon_days} 个交易日")
        print(f"  • 主动份额 (Active Share)    : {self.active_share * 100:8.2f}%")
        print(f"  • 有效持仓股票数 (ENP)      : {self.effective_stocks_count:8d} 支")
        print("-" * 70)
        print("【风控合规穿透检查】")
        print(f"  • 给定行业最大净暴露偏差     : {self.industry_max_deviation * 100:8.4f}% ")
        print(f"  • 对数市值风格净偏离 (Size) : {self.size_style_deviation:8.4f} ")
        print("=" * 70)


class AshareIndexEnhancementOptimizer:
    """
    A 股指数增强二次凸优化器
    """

    def __init__(
        self,
        risk_aversion: float = 2.0,      # 风险厌恶系数 lambda
        max_active_weight: float = 0.015, # 单只股票最大主动超配权重 +1.5%
        size_tolerance: float = 0.05,     # 市值风格偏离硬容忍上限
        max_tracking_error: float = 0.045,
        horizon_days: int = 5,
        annual_factor: float = 250.
    ):
        if risk_aversion < 0 or max_active_weight < 0 or size_tolerance < 0 or max_tracking_error <= 0 or horizon_days < 1 or annual_factor <= 0:
            raise ValueError("风险/约束参数范围不合法")
        self.max_tracking_error = max_tracking_error
        self.horizon_days, self.annual_factor = horizon_days, annual_factor
        self.risk_aversion = risk_aversion
        self.max_active_weight = max_active_weight
        self.size_tolerance = size_tolerance

    def optimize(
        self,
        expected_returns: np.ndarray,          # (N,) H 日预期超额收益率；不能传入未经校准的排序分数
        benchmark_weights: np.ndarray,     # (N,) 基准指数成分股权重 (sum=1)
        exposure_matrix: np.ndarray,       # (N, K) 因子暴露矩阵 (前 K_ind 列为行业, 之后为风格)
        factor_covariance: np.ndarray,     # (K, K) 因子协方差矩阵 F
        specific_variance: np.ndarray,     # (N,) 特异性方差对角元素 Δ
        n_industries: int = 6,             # 行业因子列数
        size_col_idx: int = 6              # 市值因子列索引
    ) -> OptimizationResult:
        """
        构建带二次风险约束的凸优化问题 问题并求解最优持仓权重
        """
        expected_returns, benchmark_weights, exposure_matrix, factor_covariance, specific_variance = validate_risk_inputs(
            expected_returns, benchmark_weights, exposure_matrix, factor_covariance, specific_variance, n_industries, size_col_idx)
        N = len(expected_returns)

        # 1. 定义优化决策变量: 投资组合最终权重 w (N,)
        w = cp.Variable(N, nonneg=True) # 单边做多约束: w_i >= 0
        h = w - benchmark_weights       # 主动偏离向量 h

        # 2. 目标函数: max h^T alpha - (lambda / 2) * (h^T Σ h)
        # 利用 Barra 形式降低维度: h^T Σ h = y^T F y + h^T Δ h
        y = exposure_matrix.T @ h       # 主动因子暴露 (K,)
        
        # 风险项: 因子风险 + 特异性风险
        factor_risk = cp.quad_form(y, factor_covariance)
        specific_risk = cp.sum(cp.multiply(specific_variance, cp.square(h)))
        portfolio_risk = factor_risk + specific_risk

        expected_return = expected_returns @ h
        period_risk = portfolio_risk * self.horizon_days / self.annual_factor
        objective = cp.Maximize(expected_return - (self.risk_aversion / 2.0) * period_risk)

        # 3. 约束条件构建
        constraints = [
            cp.sum(w) == 1.0,           # 全额投资预算约束
            w >= 0,
            portfolio_risk <= self.max_tracking_error ** 2,
        ]

        # 3.1 行业硬中性约束: X_ind^T (w - w_b) = 0
        X_ind = exposure_matrix[:, :n_industries]
        constraints.append(X_ind.T @ h == 0.0)

        # 3.2 市值风格偏离软容忍约束: |X_size^T h| <= delta
        size_exp = exposure_matrix[:, size_col_idx]
        constraints.append(cp.abs(size_exp @ h) <= self.size_tolerance)

        # 3.3 个股主动权重上限约束: w_i - w_bi <= max_active_weight
        constraints.append(h <= self.max_active_weight)

        # 二次 TE 硬约束需要锥求解器；求解后检查所有约束，不裁剪权重。
        prob = cp.Problem(objective, constraints)
        opt_w = solve_checked(prob, w, constraints)

        # 5. 体检指标测算
        active_w = opt_w - benchmark_weights
        exp_ret = float(expected_returns @ active_w)
        
        # 跟踪误差
        y_opt = exposure_matrix.T @ active_w
        f_risk = float(y_opt.T @ factor_covariance @ y_opt)
        s_risk = float(np.sum(specific_variance * (active_w ** 2)))
        te_ann = np.sqrt(f_risk + s_risk)

        # 主动份额 (Active Share = 1/2 * sum(|w - w_b|))
        active_share = float(0.5 * np.sum(np.abs(active_w)))

        # 有效持仓股票数 (Herfindahl-Hirschman: 1 / sum(w_i^2))
        enp = int(np.round(1.0 / np.sum(opt_w ** 2)))

        # 行业最大暴露偏差
        ind_bias = np.abs(X_ind.T @ active_w)
        max_ind_dev = float(np.max(ind_bias))

        # 市值暴露偏差
        size_dev = float(size_exp @ active_w)

        return OptimizationResult(
            horizon_days=self.horizon_days,
            optimal_weights=opt_w,
            expected_active_return=exp_ret,
            annualized_tracking_error=te_ann,
            active_share=active_share,
            effective_stocks_count=enp,
            industry_max_deviation=max_ind_dev,
            size_style_deviation=size_dev,
            status=prob.status
        )

9. 本讲小结与核心自测 ​

核心考点工业标准回答要点常见工程/学术陷阱
为什么个股主动偏离下限是 −wb,i？A 股公募与普通私募严禁卖空（wi≥0），主动权重 hi=wi−wb,i≥−wb,i。随意将下限设为固定的 −1%，导致基准中权重仅 0.2% 的小盘股被优化出负绝对权重（非法裸卖空）。
因子边际风险贡献（FMCAR）在组合风控中有何作用？解析计算 FMCAR=FxPA/σP，能够穿透了解每 1 单位因子暴露增加对主动跟踪误差的边际拉升作用。仅关注单因子暴露大小，忽视了因子之间协方差联动对跟踪误差的放大。
** Clarabel 求解器相比 OSQP 的本质区别？**Clarabel 支持二阶锥（SOCP），能够严格处理形如 hTΣh≤TEmax2 的二次约束；OSQP 仅支持仿射线性约束。在包含二次不等式约束时强行指定 solver=cp.OSQP，导致求解器抛出不支持的锥异常。
